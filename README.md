## Grigorii Barakhsin

Researcher at ITMO University's [Research Center "Strong AI in Industry"](https://sai.itmo.ru/en). I work on whether automated monitors
can actually read what an LLM agent did.

Two numbers, if you only read one line: established LLM judges report a failure on
clean agent traces between **34% and 78%** of the time, and **84%** of a trace by
volume contributes nothing to locating a failure.

- **[MASeval](https://github.com/sb-ai-lab/MASeval)**: automated evaluation of multi-agent systems.
  Contributor, on judge and verifier implementation and ablation tooling.
- **What Must You Log?**: what an execution trace must retain for failure
  attribution. First author; poster at the NeurIPS 2026 Verify-Agents workshop.
- **TraceJudgeBench**: 877 agent traces unified from ten judge-validation
  datasets. Co-first author; poster at the NeurIPS 2026 Verify-Agents workshop.
- **[AutoJudge](https://openreview.net/forum?id=wVp0IhPVHx)**: generating an LLM judge per trace. FAGEN @ ICML 2026.
